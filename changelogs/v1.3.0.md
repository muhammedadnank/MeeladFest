# Changelog v1.3.0 - Real-Time Festival Countdown Spotlight Banner & Homepage Feature Upgrades

**Release Date:** July 29, 2026

## 🚀 Overview

Version 1.3.0 introduces interactive feature upgrades to the MeeladFest main homepage (`/`). The flagship highlight of this release is the new **Real-Time Festival Countdown Spotlight Banner** (`<FestivalCountdownBanner />`), designed to boost user engagement with dynamic live event timers, venue & schedule metadata badges, festival switching, and direct action triggers.

---

## 🎨 Key Features & Upgrades

### 1. ⏱️ Real-Time Festival Countdown Spotlight Banner
- **Live Event Clock**: High-visibility digital countdown timer tracking Days, Hours, Minutes, and Seconds until the next upcoming festival or grand finale.
- **Dynamic Live State**: Automatically updates to a live "Festival In Progress" card with gold trophy indicator when the event target timestamp is reached.
- **Multi-Festival Selector**: Enables visitors to switch between different active or upcoming festivals directly within the spotlight banner.
- **Venue & Schedule Badges**: Visual badges for venue location, district, area, and scheduled dates styled in the Emerald & Gold Islamic Modern aesthetic.
- **Direct Action CTA**: One-click "View Festival Schedule & Live Points" button taking visitors directly to the festival's public portal (`/fests/[slug]`).

### 2. 📑 Feature Upgrade Roadmap Documentation
- **Homepage Feature Suggestions (`docs/homepage-feature-suggestions.md`)**: Created a structured upgrade blueprint documenting future interactive enhancements (Live Announcement Ticker, Universal Search Bar, Top Performers Spotlight, and Direct Certificate Finder).
