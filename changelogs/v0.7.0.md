# Changelog v0.7.0 - Certificates Engine & Malayalam Font Support

**Release Date:** July 28, 2026

## 🚀 Key Highlights & New Features

### 1. PDF Certificate Generation & Malayalam Unicode Support
- **`@react-pdf/renderer` Integration**:
  - Registered `NotoSansMalayalam` font family via CDN for full Unicode Malayalam & English rendering in PDF certificates.
  - Dynamically renders landscape A4 certificates for both **Excellence / Winner** (1st, 2nd, 3rd positions) and **Participation** certificates.
  - Elegant layout featuring festival title, madrasa name, venue, chest number, item, category, position badges, and convener signature lines.

### 2. Public Certificate Lookup Engine
- **Chest Number Search API & UI (`CertificateLookup.tsx`)**:
  - Search certificates using participant chest numbers across both single item registrations and group item entries.
  - One-click PDF download stream (`/api/fests/[festId]/certificates/download`).
  - Integrated Rate Limiting (30 requests/min per IP) to prevent server strain.

### 3. Cryptographic Verification Portal
- **HMAC-SHA256 Verification Code Engine (`lib/certificate/verify.ts`)**:
  - Reproducible verification codes (format: `MF-XXXXXXXXXX`) generated per participant, item, and certificate type.
  - Dedicated public verification portal (`/verify/[code]`) allowing inspectors and institutions to verify document authenticity.
