# Release Notes: v0.1.0

**Release Date:** 2026-07-28  
**Tag:** `v0.1.0`  
**Status:** Stable / Initial Scaffold & Base Infrastructure

---

## 🚀 Overview

`v0.1.0` marks the initial release and foundation of **MeeladFest**, a multi-tenant madrasa fest management platform. This release establishes the project architecture, complete database schemas (16 Mongoose models), authentication system, permission framework, and core administrative API routes.

---

## 📋 Highlights & Changes

### 📚 Specifications & Documentation
- **PRD (`PRD.md`)**: Complete Product Requirements Document defining problem scope, user personas (Super Admin, Sub-Admin, Public Visitor), and core feature matrix.
- **TRD (`TRD.md`)**: Technical Requirements Document outlining Next.js 14 App Router specifications, NextAuth Credentials auth, Resend email workflow, Cloudinary image upload, and `@react-pdf/renderer` PDF engine.
- **DB Schema (`DB-Schema.md`)**: Complete MongoDB schema designs for all 16 collections with indexing rules and soft-delete safeguards.
- **Implementation Plan (`Implementation-Plan.md`)**: Phased execution plan from Phase 0 (Scaffold) through Phase 9 (Polish).

### 🗄️ Database Models (Mongoose & TypeScript)
Implemented 16 strongly typed Mongoose models in `src/models/`:
- **Identity & Access**: `User`, `PasswordReset`, `Fest`, `FestAdmin`
- **Competition & Structure**: `Team`, `Category`, `Item`, `Participant`, `GroupEntry`, `Result`
- **Public & Festival Engagement**: `Program`, `Update`, `Gallery`, `Faq`, `Feedback`, `ActivityLog`

### 🔒 Auth & Security Infrastructure
- Integrated NextAuth.js with JWT session strategy and bcrypt password hashing.
- User registration API (`/api/auth/register`).
- Role-based authorization helper `getFestPermission()` supporting owner vs. sub-admin granular permissions (`participants`, `results`, `updates`, `gallery`).
- Audit logging helper `logActivity()` for recording administrative actions.

### 🌐 Fest Management APIs
- `/api/fests` & `/api/fests/[festId]`: Fest creation, editing, and soft-deletion.
- `/api/fests/[festId]/subadmins` & `.../[adminId]`: Sub-admin invite system, permission toggles, and access revocation.
- `/api/fests/public`: Public fest discovery endpoint.

### 🖥️ User Interface
- Public Homepage (`src/app/page.tsx`) showcasing active fests and feature overviews.
- Admin Login (`src/app/(auth)/login/page.tsx`) and Register (`src/app/(auth)/register/page.tsx`) pages.
- Admin Dashboard shell (`src/app/dashboard/page.tsx`).
