# Release Notes: v0.5.0

**Release Date:** 2026-07-28  
**Tag:** `v0.5.0`  
**Status:** Released / Phase 3: Public Fest Page, Countdown & Program Schedule

---

## 🚀 Overview

`v0.5.0` introduces the public festival visitor experience for **MeeladFest**. Anyone can now access public festival pages via `/fests/[slug]`, view real-time competition standings, check the live event countdown timer, and browse the full festival program schedule.

---

## 📋 Highlights & Changes

### 🌐 Public Festival Page (`/fests/[slug]`)
- **Route & Page**: `src/app/fests/[slug]/page.tsx` displaying festival overview, venue info, countdown widget, live standings, and program schedule.
- **Dynamic SEO Metadata**: Uses Next.js `generateMetadata` for dynamic page titles, descriptions, and OpenGraph tags per festival.
- **Festival Lookup Helper**: Helper `getFestBySlugOrId` in `src/lib/getFest.ts` enabling seamless lookup by Mongo ID or URL slug while strictly hiding soft-deleted festivals.

### ⏱️ Live Event Countdown Component
- **Countdown Widget**: `src/components/public/FestCountdown.tsx` displaying real-time days, hours, minutes, and seconds until the festival date, with live status indicators.

### 📅 Program Schedule API & Timeline Component
- **Programs API**: `/api/fests/[festId]/programs` (GET public schedule, POST owner create) and `/api/fests/[festId]/programs/[programId]` (PUT/DELETE owner management).
- **Public Schedule Widget**: `src/components/public/PublicPrograms.tsx` rendering an interactive timeline with time badges, titles, and details.

### 🏆 Interactive Public Leaderboard
- **Public Leaderboard Widget**: `src/components/public/PublicLeaderboard.tsx` with team standings (with progress indicators & position tallies) and individual championship search & category filtering.

---

## 🔒 Security & Privacy
- Public routes restrict visibility to active, non-deleted festivals only.
- Program management API endpoints are strictly gated by fest owner permissions.
