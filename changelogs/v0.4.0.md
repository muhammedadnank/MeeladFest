# Release Notes: v0.4.0

**Release Date:** 2026-07-28  
**Tag:** `v0.4.0`  
**Status:** Released / Phase 5: Results Declaration & Leaderboard Engine

---

## 🚀 Overview

`v0.4.0` implements the winner declaration engine, team leaderboard aggregation, and individual championship point calculations for **MeeladFest**. Administrators can now record 1st, 2nd, and 3rd place winners per item, while automatic point calculation updates live team standings.

---

## 📋 Highlights & Changes

### 🥇 Results Declaration API
- **API Route**: `GET`, `POST` on `/api/fests/[festId]/results`.
- **Position Allocation**: Supports assigning 1st, 2nd, and 3rd positions for single events (participants) and group events (teams).
- **Automated Points Calculation**: Calculates points automatically using custom item points or system defaults, with built-in group item point multipliers.
- **Uniqueness Safeguard**: Strictly prevents duplicate position assignments per competition item.

### 📊 Leaderboard & Championship Analytics API
- **Team Leaderboard Route**: `GET` on `/api/fests/[festId]/leaderboard/teams` aggregating total points, position tallies (1st, 2nd, 3rd counts), and handling ties with equal rank assignments.
- **Individual Championship Route**: `GET` on `/api/fests/[festId]/leaderboard/championship` ranking individual participant performance across single events.

### 🖥️ Admin Winner Declaration UI
- **Results Admin Interface**: `/dashboard/fests/[festId]/results` providing dynamic item selection, participant/team picker, live position assignment, and existing results management.

---

## 🔒 Permission & Security
- Gated by `results` sub-admin permission or festival ownership.
- Atomic updates preventing partial result state corruption.
