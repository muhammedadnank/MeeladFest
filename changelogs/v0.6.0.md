# Changelog v0.6.0 - Advanced Admin Management & Security Polish

**Release Date:** July 28, 2026

## 🚀 Key Highlights & New Features

### 1. Festival Admin Management Dashboard Pages
- **Live Updates Admin (`/dashboard/fests/[festId]/updates`)**:
  - Full CRUD interface to publish, toggle importance/pin status, and remove real-time announcements.
- **Photo Gallery Admin (`/dashboard/fests/[festId]/gallery`)**:
  - Upload/add photo URLs with captions and manage image collections with quick preview links.
- **FAQs Admin (`/dashboard/fests/[festId]/faqs`)**:
  - Create, update, and order frequently asked questions and answers displayed on the public fest page.
- **Visitor Feedback Admin (`/dashboard/fests/[festId]/feedback`)**:
  - Review ratings, comments, and metrics (average score, total feedback count) with delete permissions.
- **Activity Log Audit Trail (`/dashboard/fests/[festId]/activity-log`)**:
  - Comprehensive log browser showing timestamps, user details, action types, and metadata for audit compliance.

### 2. Rate Limiting & Security Infrastructure
- **Mongo-backed Rate Limiter (`lib/rate-limit.ts` & `models/RateLimit.ts`)**:
  - Built-in TTL index for auto-expiration.
  - Implemented on public endpoints (`/certificates/lookup` at 30 req/min, `/feedback` at 5 req/min).

### 3. Public Festival Page Integrations
- Integrated `PublicUpdates`, `PublicGallery`, `PublicFaqAccordion`, `PublicFeedbackForm`, and `PublicChampionshipLeaderboard` seamlessly on `/fests/[slug]`.
