# MeeladFest Release v1.6.0 - Search Engine Optimization (SEO) & Dynamic Indexing Suite

**Release Date:** July 29, 2026  
**Theme:** Search Engine Optimization, Dynamic XML Sitemap, Robots.txt & Social OpenGraph Metadata  

---

## 🌟 Overview & Key Upgrades

Release **v1.6.0** introduces a comprehensive **SEO & Indexing Suite** for the MeeladFest platform. This update enables search engines (Google, Bing) to efficiently crawl, index, and surface all festival events, scoreboards, and competition updates while delivering high-quality rich social preview cards across messaging and social media platforms.

---

### ✨ Key Features

1. **🗺️ Dynamic XML Sitemap (`src/app/sitemap.ts`)**:
   - Auto-generates standard XML sitemap entries at `/sitemap.xml`.
   - Dynamically fetches all published festival slugs from MongoDB (`/fests/[slug]`) with `daily` change frequency and `0.8` priority.
   - Includes core static routes (`/`, `/login`, `/register`).

2. **🤖 Crawler Control Policy (`src/app/robots.ts`)**:
   - Generates `/robots.txt` regulating search crawler behavior.
   - Grants full crawling access to public routes while restricting sensitive administrative and internal API endpoints (`/dashboard/`, `/api/`).
   - Links directly to the dynamic XML sitemap URL.

3. **📱 Enhanced Root Metadata & Social Sharing (`src/app/layout.tsx`)**:
   - **`metadataBase`**: Configured environment-aware URL resolution (`NEXT_PUBLIC_APP_URL` fallback) preventing Next.js metadata warnings.
   - **OpenGraph & Twitter Cards**: Full support for `summary_large_image` cards, title templates, descriptions, and site branding.
   - **Targeted Keywords**: Added relevant search keywords for madrasa competitions, live scoreboards, and certificate verification.
