# MeeladFest Release v1.5.0 - Interactive 3D Three.js Hero Visuals

## 🌟 Overview
Release **v1.5.0** introduces a high-performance **Three.js 3D WebGL Canvas** integration for the MeeladFest platform. This update adds an interactive 3D Gold Crescent Moon & Star celestial model combined with glowing ambient 3D stardust particles to elevate the platform's visual presentation.

---

### ✨ Key Upgrades & Features

1. **Interactive 3D Crescent & Star Model (Option 1)**:
   - Built custom extruded 3D geometry for the **Gold Crescent Moon** and **5-Pointed Star** using `THREE.ExtrudeGeometry` and `THREE.Shape`.
   - Applied realistic metallic shaders (`THREE.MeshStandardMaterial`) with golden reflections (`#F59E0B`), metalness, and subtle emissive glow.
   - Smooth continuous auto-rotation with gentle vertical floating motion.

2. **Ambient Gold Stardust Particle Cloud (Option 3)**:
   - Rendered 280+ glowing 3D light particles floating upwards using `THREE.Points` and custom radial canvas textures.
   - Dynamic pulsing point lights and emerald rim lighting (`#34D399`) for depth.

3. **Interactive Parallax Tilt**:
   - Responds dynamically to user mouse movement across the screen, applying real-time 3D camera tilt and rotation.

4. **Performance & Viewport Optimization**:
   - Integrated `IntersectionObserver` to automatically pause the WebGL animation loop when the Hero section is scrolled offscreen or when the browser tab is hidden/inactive, reducing CPU/GPU overhead to zero when not visible.
   - Added robust `try-catch` WebGL context initialization fallback to safely handle hardware/browser WebGL restrictions gracefully without crashing.
   - Clean lifecycle management with full WebGL memory disposal (`geometry.dispose()`, `material.dispose()`, `renderer.dispose()`) on component unmount.
   - Client-side rendering integration ensuring zero SSR hydration mismatches in Next.js.
