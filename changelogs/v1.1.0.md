# Changelog v1.1.0 - Public UI/UX Overhaul & Stability Enhancements

**Release Date:** July 29, 2026

## 🚀 Overview

Version 1.1.0 introduces a comprehensive UI/UX redesign of the public festival portal, incorporating top 3 podium showcases, category filters, live auto-polling indicators, and critical stability fixes for serverless database execution and client-side hydration.

---

## 🎨 Key Features & UI/UX Upgrades

1. **Individual Championship Leaderboard (`PublicChampionshipLeaderboard`)**:
   - **Top 3 Winners Podium**: Styled podium display for 1st (Gold 🥇), 2nd (Silver 🥈), and 3rd (Bronze 🥉) rank holders with custom color glows and rank badges.
   - **Category Filtering**: Added category filter pills (e.g. Sub-Junior, Junior, Senior) allowing visitors to filter rankings per category.
   - **Instant Search**: Real-time filtering by participant chest number or name.
   - **Position & Team Badges**: Visual indicators for rank, chest numbers, and team color tags.

2. **Live Team Standings Leaderboard (`PublicLeaderboard`)**:
   - **Top 3 Team Podium**: Visualized leading teams on a podium with total points callouts.
   - **Animated Progress Bars**: Percentage-based visual score breakdown for all participating teams.
   - **Real-Time Polling Indicator**: Live auto-polling status badge with 30-second refresh timer.

3. **Public Festival Portal Polish**:
   - Responsive tabbed navigation for switching between Team Points and Individual Championship rankings.
   - Integrated live updates, program timeline, photo gallery, certificate search, and feedback forms into a unified layout.

---

## 🐛 Bug Fixes & Stability Enhancements

1. **React Hydration Error #418 Resolution**:
   - Resolved hydration mismatch in `FestCountdown` component by introducing a client-side `mounted` state check, ensuring 100% initial SSR/Client HTML parity.

2. **Graceful Certificate Search**:
   - Updated `/api/fests/[festId]/certificates/lookup` to return HTTP 200 OK with formatted user messages for missing/unassigned chest numbers, eliminating red HTTP 404 network errors in DevTools.

3. **Serverless Mongoose Population Fix**:
   - Explicitly imported and registered all Mongoose models (`Team`, `Category`, `Participant`, `Result`, `GroupEntry`, `Item`, `Fest`) in `src/lib/db.ts` to prevent `MissingSchemaError` in Vercel serverless runtime.

---

## 🛠️ Developer & Tooling Updates

1. **Database Seed Script**:
   - Added `scripts/seed.ts` allowing quick population of realistic test data (teams, categories, single/group items, participants, and results) for local development and demonstration.
